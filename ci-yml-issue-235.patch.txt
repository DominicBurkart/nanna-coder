## What this patch does

1. **Removes the broken curl probe** at ci.yml:150-154. The old probe checked for
   `http://localhost:11434/api/tags` but nothing ever started Ollama on the host,
   so `--run-ignored ignored-only` was always silently skipped.

2. **Starts Ollama** via the existing `nanna-coder-ollama:latest` image (already
   loaded into Docker by the `Pre-build test containers` step), polls readiness
   with a hard 120s ceiling, and pulls `qwen3:0.6b` (the model the 8 ignored
   tests in `model/tests/ollama_chat_integration.rs` expect).

3. **Adds a pre-flight guard**: counts ignored tests via `cargo nextest list
   --run-ignored ignored-only --message-format json` and fails CI if fewer than
   11 are found. Catches future silent regressions where someone removes
   `#[ignore]` or accidentally filters out tests. The floor is a commit-visible
   constant; bumping it is a one-line reviewable change.

4. **Runs ignored tests unconditionally** with `--no-tests=fail` — belt and
   suspenders for the count guard.

5. **Extends the same setup to the `security` (tarpaulin) leg** and adds
   `--run-ignored` to tarpaulin, so Codecov sees coverage from the now-running
   tests. Paired with `tarpaulin.toml` (model/tests exclude removed in the same
   commit), this closes the Codecov detection gap.

6. **Teardown** on both legs with `if: always() && matrix.test-type == '...'`.

Harness tests (`harness/tests/dev_container_integration.rs`,
`harness/tests/nanna_self_dev_integration.rs`) spawn their own Ollama container
via `harness::container::start_container_with_fallback` and pull `gemma4:e4b`
themselves, so no host setup is needed for them.
