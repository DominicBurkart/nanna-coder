Follow-up patch for .github/workflows/ci.yml (issue #235).

Two CI failures observed after the initial ci.yml patch landed
(commit c76a1ea):

1. `integration-container` failed at "Assert expected ignored-test count"
   with exit code 5. The jq expression against `cargo nextest list
   --message-format json` does not match nextest's actual schema
   (nextest output either uses different keys or emits non-object root).

2. `security` (tarpaulin) failed with exit code 2 on "Run security checks".
   Most likely the top-level `--run-ignored` flag isn't recognized by the
   nixpkgs-pinned cargo-tarpaulin version. The rust test-harness has had a
   stable `--include-ignored` flag for years; passing it via `--` is safer.

This session's GitHub App token lacks the `workflows` permission, so the
fix must be applied manually. From the repo root:

    git apply ci-yml-issue-235-followup.patch
    rm ci-yml-issue-235-followup.patch
    git add .github/workflows/ci.yml
    git commit -m "ci: fix #235 guards (grep count + tarpaulin flag)"
    git push
